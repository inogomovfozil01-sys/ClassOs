# ClassOS

Электронный дневник одного класса: расписание, домашние задания, новости, файлы, чат и таблицы.

## Локальный запуск

1. Установите Node.js и зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env`, заполните собственные значения.
3. Выполните `npx prisma generate` и `npx prisma db push`.
4. Запустите `npm run dev`, откройте `http://localhost:3000/setup` и создайте владельца.

Не запускайте `db:seed` на рабочей базе: это демонстрационные аккаунты и данные.

Проверки: `npm test`, `npm run lint`, `npm run build`.

## Развёртывание

Локально приложение использует SQLite, диск и Socket.IO через `server.js`.

На Vercel сборка создаёт PostgreSQL-схему из основной Prisma-схемы. Перед первым запуском примените её к облачной базе. Файлы сохраняются в базе и выдаются после авторизации; размер загрузки ограничен 4 МБ. Чат проверяет сообщения каждые 4 секунды, индикаторы присутствия и набора текста требуют локального Socket.IO-сервера. Напоминания проверяются ежедневным Vercel Cron; уведомление о подтверждении eMaktab может поступить в течение суток после истечения пяти дней.

В Production Environment Variables задайте `DATABASE_URL`, случайные `AUTH_SECRET` и `CRON_SECRET`, `GEMINI_API_KEY`, `NEXT_PUBLIC_SERVERLESS=1`, `NEXT_PUBLIC_MAX_UPLOAD_MB=4`. Для базы вне Railway используйте публичный TCP-адрес. Не переносите локальные сессии или демонстрационные аккаунты в рабочую базу.

`.env`, локальные базы, пользовательские загрузки и QA-артефакты не входят в репозиторий. Секреты задаются в настройках выбранного хостинга.
